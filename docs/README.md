# Documentation

- [Writing equations](writing-equations.md): how to use the editor. How typing is turned
  into mathematics (names, numbers, functions, constants, conditions, piecewise
  definitions), with the reasons behind each rule, plus editing, selection, copy and
  paste, and export. Start here.
- [Equation editor design](design.md): how the editor works inside. The layout-tree and
  cursor model, parsing, rendering and caret placement, editing and undo, the clipboard,
  exports and CellML mode, testing, future work and open questions.
- [Component interface](component-interface.md): for applications using the editor. The
  `EquationWorkbench` props and event, and how a units checker connects to it.
